# Indian VC tech stack — IndianVCs.com

Tool inventory by category as catalogued for Indian funds:

- **CRM (10):** Notion, Attio, Taghash, Affinity, Airtable, Asana, Clay, Folk, HubSpot, Streak
- **Data (13):** Evertrace, CB Insights, Harmonic, PitchBook, Crunchbase, LinkedIn Sales Nav, Preqin, Private Circle, Sanchi Connect, Tracxn, Twitter, Venture Intelligence
- **Research (14):** Evertrace, 1Lattice, Ahrefs, AlphaSense, Clearbit, Data AI, G2, Gartner, GLG, Kavi Research, Owler, RedSeer, SEMRush, Similarweb, Statista
- **AI (6):** ChatGPT, Claude, Perplexity, DeepSeek, Gemini, Manus
- **News (14):** Inc42, Arc, Economic Times, Entrackr, Entrepreneur India, Forbes, Ken, Live Mint, Money Control, TechCrunch, The Generalist, The Morning Context, VCCircle, YourStory
- **Portfolio mgmt (4):** Taghash, Carta, Standard Metrics, Vestberry

India-built: **Taghash, Sanchi Connect, Tracxn, Venture Intelligence**.

Editorial framing: "AI now sits as a layer across the stack, not a separate beat" — Claude leads for memo drafting and data-room synthesis; ChatGPT covers firm-playbook GPTs; Perplexity/Exa for cited quick research. Most sub-5-person funds run on five tools: a CRM, a data provider, a workspace, AI, and email.
