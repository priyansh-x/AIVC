# Taghash

What it is: an India-built VC operating system — dealflow + CRM + fund mgmt + portfolio + LP module + fund-of-funds.

Customers (named publicly): **Blume Ventures, Kalaari Capital, A91 Partners**, Elevar Equity, 360.one, KIFL. "60+ leading firms."

MCP server: secure bridge that exposes a fund's live deal-flow, CRM, fund, portfolio, LP, contact-book and MIS data to Claude, OpenAI, Copilot, etc. Use cases pitched: AI-score and enrich inbound deal flow, auto-draft board packs and LP reports, run live portfolio runway/burn/risk analysis, draft founder follow-ups and LP outreach.

Interpretation: Indian funds have *already* expressed preference for *context-aware, governed, ops-integrated AI* over standalone AI tools. Taghash is positioning itself as the system of record under any AI agent layer in India. This is the closest existing competitor to "AIVC's AI brain on a fund's workflow" — but Taghash is selling tooling to existing funds, not running its own fund.
