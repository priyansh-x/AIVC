# Correlation Ventures

Key points:
- Founded by David Coats + Trevor Kienzle (HBS). Built proprietary database via Dow Jones partnership + NDAs with 20+ funds.
- Quant model evaluates company, round, investor signals; predicts return outcomes.
- Always co-invests alongside a lead — "frictionless co-investor" positioning.
- Decisions in days, always under 2 weeks.
- Limitation: model only works because they ride on lead's diligence. Not a model for solo conviction.

Cross-refs: MIT Technology Review "An Algorithm to Pick Startup Winners"; HBS Digital Innovation case.
