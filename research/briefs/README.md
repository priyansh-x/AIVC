# Briefs

The only thing the CEO is required to read.

- One brief per question. ≤1 page.
- Filename: `<YYYY-MM-DD>-<slug>.md`.
- Generated via the `draft-brief` skill or directly by the `research-analyst` sub-agent at the end of any research task.
- Template: [`../../docs/brief-template.md`](../../docs/brief-template.md).

If a brief is over 1 page, it's not done.
