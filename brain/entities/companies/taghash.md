# Taghash

The India-built VC operating system: dealflow + CRM + fund management + portfolio + cap-table + LP module + fund-of-funds. Bengaluru, founded 2017. **60+ Indian fund customers including Blume, Kalaari, A91, Elevar, 360.one, KIFL.**

Shipped the first VC MCP server: exposes a fund's live deal-flow, CRM, portfolio, LP and contact-book data to Claude / OpenAI / Copilot. Stated AI use-cases: AI-scored inbound deal flow, auto-drafted board packs and LP reports, live portfolio runway/burn analysis, founder-follow-up drafting.

Relevance to AIVC: the closest existing competitor for the *workflow layer* of the associate-stack-collapse wedge — but with a critical positioning difference. Taghash sells *tooling* to existing funds. AIVC's frame is to *run* the fund using a similar stack as the moat. If AIVC's customer-discovery shows that funds want a workflow product, Taghash + MCP is a credible buy/integrate option, not a build-from-scratch one. The 3000+ Indian startup dataset becomes the differentiating ingredient on top of (or sold beside) Taghash's plumbing, not a substitute for it.
